# GameStation

A pure and immersive game walkthrough and gallery website, focusing on PS5 games.
打造最极致的游戏探索体验。

## Introduction

GameStation was born from the desire for a clean, ad-free, and focused game information platform. Unlike other platforms cluttered with ads and chaotic forums, GameStation provides pure information retrieval for gamers who just want to enjoy the game.

## Features

- **Game Gallery**: Browse a curated collection of PS5 games.
- **Walkthroughs**: Detailed guides for games (currently featuring The Last of Us Part I).
- **Clean UI**: No ads, no forums, just game content.

## Tech Stack

- **Frontend**: React + Vite
- **Styling**: TailwindCSS
- **Routing**: React Router
- **Icons**: Lucide React

## Project Structure

- `ps5-gallery/`: The main frontend application source code.
- `picture/`: Static assets and game covers.

## Getting Started

1.  Clone the repository:
    ```bash
    git clone https://github.com/yenicee1014/GameStation.git
    ```

2.  Navigate to the project directory:
    ```bash
    cd GameStation/ps5-gallery
    ```

3.  Install dependencies:
    ```bash
    npm install
    ```

4.  Run the development server:
    ```bash
    npm run dev
    ```
